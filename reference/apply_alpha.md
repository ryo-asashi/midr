# Apply Alpha Transparency to Colors (Vectorized & NA-safe)

Apply Alpha Transparency to Colors (Vectorized & NA-safe)

## Usage

``` r
apply_alpha(col, alpha = NULL)
```

## Arguments

- col:

  a vector of R colors (names, hex strings, or integer indices).

- alpha:

  a numeric vector of alpha values in `[0, 1]`.

## Value

a character vector of hex colors with alpha channel.
